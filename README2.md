# Smart Canteen Management System

A smart college canteen web application designed to reduce crowding and waiting time through digital table booking and food ordering.

## Features

- Table booking with time slots
- Small booking fee
- 15-minute rescheduling option
- Online food ordering
- Order token generation
- Order-ready notification
- Booking and order status tracking

## Purpose

The system helps students avoid long queues and crowded canteen areas by allowing them to reserve tables and place food orders digitally.

## Development

This project was developed using **Bolt.new**, an AI-assisted development platform.
